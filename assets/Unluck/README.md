# Unluck — Leitor digital

Interface de leitura em HTML, CSS e JavaScript puro.

## Como executar
1. Extraia a pasta `unluck-reader`.
2. Abra `index.html` no navegador. Não precisa instalar dependências.
3. Para desenvolvimento local, também pode usar a extensão Live Server do VS Code.

## Arquivos
- `index.html`: estrutura da interface.
- `style.css`: tema dark, responsividade e componentes visuais.
- `script.js`: navegação, pesquisa, marcadores e preferências.
- `book.js`: texto do livro extraído do arquivo DOCX enviado.

## Recursos
- Sumário por capítulos e volumes identificados no documento.
- Pesquisa no texto incluído.
- Marcadores por capítulo.
- Salvamento local da posição e das preferências.
- Controles de fonte, espaçamento e largura.
- Atalhos de teclado: ← e → para trocar de capítulo; Esc para fechar painéis.

Os dados de leitura ficam no armazenamento local do navegador.
